## Project Description

Ibn Al-Arab is a bilingual (English/Arabic) meal delivery platform built with React, TypeScript, and Vite. The application features meal browsing, user authentication, checkout process, and admin functionality.



## Technologies

- React
- TypeScript
- Vite
- Tailwind CSS
- Supabase (Auth & Database)
- React Router
- React Context API
- shadcn/ui components
- i18next for internationalization
