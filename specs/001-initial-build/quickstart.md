# Quickstart — 001-initial-build

Purpose
-------

This quickstart explains how to set up the runtime environment and admin configuration required to run the initial-build feature locally.

Requirements
------------

- Node.js >= 18, npm or pnpm
- Supabase project for Auth, Postgres, and Storage
- Environment variables: `SUPABASE_URL`, `SUPABASE_SERVICE_KEY`, `SUPABASE_ANON_KEY`, `CURRENCY`, `VAT_RATE`, `PLAN_PRICES` (map), `PRODUCT_SIGNOFF_REQUIRED` (placeholder until PO signs off)

Notes on runtime config
- Pricing and plan values are stored in Supabase tables (see `local files/Existing DB tables.txt`) and should be read at runtime by the backend. Do not hardcode numeric values. The canonical list of delivery districts is available at `local files/districts.txt` and should be used to seed `DELIVERY_DISTRICTS`.

Local run
---------

1. Install dependencies:

```bash
npm install
```

2. Start the dev server (frontend):

```bash
npm run dev --workspace client
```

Admin setup
-----------

- Ensure `PLAN_PRICES` and `VAT_RATE` are set in the admin runtime configuration before enabling checkout.
- `PRODUCT_SIGNOFF_REQUIRED` must be cleared by the Product Owner prior to merging any changes that affect pricing or delivery rules.
