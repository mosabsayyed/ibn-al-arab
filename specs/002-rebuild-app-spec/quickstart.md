# Quickstart: Rebuild app spec

Prerequisites
- Node.js installed (>=16)
- Supabase project for Auth, Postgres, Storage
- Environment variables configured via `.env` or secret manager (see CONFIG.md)

Local dev
1. Install dependencies: `npm install`
2. Start dev server: `npm run dev`
3. Run tests: `npm test`

Admin setup (protected)
- Configure `PLAN_PRICES`, `VAT_RATE`, `CURRENCY`, `DELIVERY_DISTRICTS` via admin UI or secure endpoint. PO signoff required before enabling checkout.
	- Note: `PLAN_PRICES`, `VAT_RATE`, and `CURRENCY` are stored in Supabase tables (the tables already exist; see `local files/Existing DB tables.txt`). Do not hardcode numeric prices. The canonical delivery districts list is available at `local files/districts.txt` and should be used to seed `DELIVERY_DISTRICTS`.
